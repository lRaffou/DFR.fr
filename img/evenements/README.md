# Dossier des Événements

Ce dossier contient les photos des événements de Dao Family Records.

## Structure des fichiers

-   Les images doivent être au format JPG ou PNG
-   Les noms des fichiers doivent correspondre aux références dans `data/evenements.php`
-   Taille recommandée : 1200x800 pixels minimum
-   Poids maximum recommandé : 1MB
