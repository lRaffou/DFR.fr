# Dossier des Artistes

Ce dossier contient les photos des artistes de Dao Family Records.

## Structure des fichiers

-   Les images doivent être au format JPG ou PNG
-   Les noms des fichiers doivent correspondre aux références dans `data/artistes.php`
-   Taille recommandée : 800x800 pixels minimum
-   Poids maximum recommandé : 500KB
